**# Credit Card Weekly Analytics Dashboard

## Power BI Dashboard Project

---

## Project Objective

The objective of this project is to develop an interactive Credit Card Weekly Analytics Dashboard that provides insights into revenue performance, customer behaviour, transaction trends, card category performance, activation metrics, and delinquency analysis.

The dashboard enables stakeholders to monitor weekly business performance and make data-driven decisions.

---

## Dataset

**Dataset Type:** Financial Dataset

The project uses:

- Customer details dataset
- Credit card transaction dataset
- Weekly customer and transaction performance data

---

## Tools & Technologies

- CSV Files
- PostgreSQL
- SQL
- Power BI
- DAX

---

## Project Workflow

### 1. Data Preparation
- Prepared raw customer and transaction CSV datasets
- Reviewed dataset structure and required fields

### 2. Database Creation & Data Import
- Created tables in PostgreSQL
- Imported CSV files using SQL COPY command
- Loaded structured data into database tables

### 3. Power BI Dashboard Development
- Connected PostgreSQL database with Power BI
- Created KPI metrics using DAX
- Developed interactive dashboards for analysis

### 4. Weekly Refresh Validation
- Added new weekly data (Week 53)
- Refreshed dashboard data
- Validated updated revenue, transaction, and customer metrics
